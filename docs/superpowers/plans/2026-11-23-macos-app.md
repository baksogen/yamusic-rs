# macOS-приложение: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Яндекс Музыка RS собирается под macOS как universal `.app` в `.dmg`: нативное окно, медиаклавиши и «Сейчас играет», токен в Keychain, значок в строке меню, возврат окна из Dock, корректный ⌘Q.

**Architecture:** macOS-слой переносится из форка `rnikitin/yamusic-rs` (ветка `rnikitin/main`, уже скачана как `refs/remotes/rnikitin/main`) — только файлы и хунки про macOS. Его `src/mac.rs` (526 строк) делится на модуль `src/mac/` по ответственности. Keychain, строка меню, Dock и ⌘Q пишутся заново на тех же прямых вызовах objc runtime, что и код форка: новых крейтов, кроме `security-framework`, нет.

**Tech Stack:** Rust 1.98, Slint 1.18 (winit 0.30.13, skia-software), objc runtime через `extern "C"`, MediaPlayer.framework, `security-framework` 3, `lipo`, `codesign`, `hdiutil`.

## Исполнители

- Код по задачам пишет субагент на **haiku** (`model: "haiku"`), по одной задаче на агента; в промпт — текст задачи целиком плюс раздел Global Constraints.
- После каждой задачи старшая модель (opus или sonnet) проверяет diff и прогоняет clippy/тесты. Замечания — обратно исполнителю той же задачи.
- Ручные проверки окна, Dock, меню и Keychain делает пользователь: субагент интерфейс не видит.

## Global Constraints

- Bundle ID, метка LaunchAgent и service в Keychain: `io.github.baksogen.yamusic-rs`.
- Репозиторий релизов: `https://github.com/baksogen/yamusic-rs` (поле `repository` в `Cargo.toml`).
- Подпись: ad-hoc (`SIGN_ID` по умолчанию `-`), Developer ID — сменой `SIGN_ID`.
- CI (`.github/workflows/build.yml`) не трогать.
- Windows и Linux должны собираться как раньше: всё macOS-специфичное — под `#[cfg(target_os = "macos")]` или `App.mac` в Slint.
- Из форка НЕ брать: GPU-рендер, `src/fade.rs`, правки player/stream/net/api/images/landing, rodio 0.22, манифест Windows, тосты с кнопкой.
- Код форка — GPL-3.0, как и наш: в сообщении коммита с перенесённым кодом указывать `Based on rnikitin/yamusic-rs`.
- Новые файлы — до ~200 строк (правило пользователя). Исключение: `src/mac/window.rs` (~250 строк перенесённого кода).
- Не создавать документацию и описания изменений; README не трогать.
- Проверка каждого шага сборки: `cargo clippy --release --target <triple> -- -D warnings` для `aarch64-apple-darwin` и `x86_64-apple-darwin`.
- Коммиты — локально в ветку `macos-app`, без push.

```rust
/// macOS: generic password в связке «Вход». Доступ привязан к подписи приложения:
/// после обновления ad-hoc-сборки macOS один раз спросит разрешение.
#[cfg(target_os = "macos")]
mod keychain {
    use crate::config::log;
    use security_framework::passwords::{delete_generic_password, get_generic_password, set_generic_password};

    const SERVICE: &str = "io.github.baksogen.yamusic-rs";

    pub fn store(name: &str, secret: &str) -> bool {
        set_generic_password(SERVICE, name, secret.as_bytes()).map_err(|e| log(format!("Keychain: запись {name}: {e}"))).is_ok()
    }

    pub fn load(name: &str) -> Option<String> {
        String::from_utf8(get_generic_password(SERVICE, name).ok()?).ok()
    }

    pub fn remove(name: &str) {
        let _ = delete_generic_password(SERVICE, name);
    }
}

#[cfg(target_os = "macos")]
const IN_KEYCHAIN: &str = "keychain:";
```

### Task 4: Закрытие окна, клик по Dock, ⌘Q

**Files:**

**Interfaces:**

Почему так: winit 0.30.13 (`platform_impl/macos/app_state.rs`) не реализует `applicationShouldHandleReopen:hasVisibleWindows:` и `applicationShouldTerminate:`. Без первого спрятанное окно из Dock не вернуть. Без второго ⌘Q завершает процесс прямо из `applicationWillTerminate:`, мимо `save_places` и `sys::cleanup` в `gui::run`. Методы добавляются в класс делегата winit, затем делегат переустанавливается: NSApplication кэширует, на что отвечает делегат, в момент `setDelegate:`.

```rust
//! macOS: клик по значку в Dock возвращает спрятанное окно; ⌘Q, «Завершить» в Dock
//! и выход из системы закрывают приложение через наш quit(), с сохранением окна.
//! Методы добавляются в делегат winit (WinitApplicationDelegate): сам winit их не реализует.

use super::objc::*;
use std::cell::RefCell;
use std::ffi::c_void;

#[derive(Clone, Copy)]
pub enum Event {
    Reopen,
    Quit,
}

thread_local! {
    static HANDLER: RefCell<Option<Box<dyn Fn(Event)>>> = const { RefCell::new(None) };
}

/// Из обработчика AppKit в Slint не заходим: откладываем в цикл событий.
fn fire(e: Event) {
    let _ = slint::invoke_from_event_loop(move || {
        HANDLER.with(|h| {
            if let Some(f) = h.borrow().as_ref() {
                f(e);
            }
        })
    });
}

/// applicationShouldHandleReopen:hasVisibleWindows:
extern "C" fn should_reopen(_s: Id, _sel: Sel, _app: Id, _visible: bool) -> bool {
    fire(Event::Reopen);
    true
}

/// applicationShouldTerminate: — NSTerminateLater (2): система ждёт, а процесс
/// завершает gui::run после сохранения окна. Cancel сорвал бы выход из системы.
extern "C" fn should_terminate(_s: Id, _sel: Sel, _app: Id) -> usize {
    fire(Event::Quit);
    2
}

/// Звать из главного потока после создания окна: делегат winit уже установлен.
pub fn install(on_event: impl Fn(Event) + 'static) {
    HANDLER.with(|h| *h.borrow_mut() = Some(Box::new(on_event)));
    unsafe {
        let cls = objc_getClass(c("WinitApplicationDelegate").as_ptr());
        if cls.is_null() {
            crate::config::log("mac: делегат winit не найден, Dock и ⌘Q без обработчиков");
            return;
        }
        class_addMethod(
            cls,
            sel_registerName(c("applicationShouldHandleReopen:hasVisibleWindows:").as_ptr()),
            should_reopen as *const c_void,
            c("B@:@B").as_ptr(),
        );
        class_addMethod(cls, sel_registerName(c("applicationShouldTerminate:").as_ptr()), should_terminate as *const c_void, c("Q@:@").as_ptr());
        // NSApplication запоминает методы делегата при setDelegate: — переустанавливаем.
        // Делегат держит winit, сброс в nil его не освобождает.
        let app = msg0(objc_getClass(c("NSApplication").as_ptr()), "sharedApplication");
        let delegate = msg0(app, "delegate");
        msg_set_id(app, "setDelegate:", std::ptr::null_mut());
        msg_set_id(app, "setDelegate:", delegate);
    }
}
```

```rust
    Next,

    Quit,

extern "C" fn on_item(_s: Id, _sel: Sel, item: Id) {
    let tag: c_long = unsafe {
        let f: unsafe extern "C" fn(Id, Sel) -> c_long = std::mem::transmute(objc_msgSend as unsafe extern "C" fn() as usize);
        f(item, sel_registerName(c("tag").as_ptr()))
    };
    let Some(&e) = EVENTS.get(tag as usize) else { return };
    let _ = slint::invoke_from_event_loop(move || {
        HANDLER.with(|h| {
            if let Some(f) = h.borrow().as_ref() {
                f(e);
            }
        })
    });
}

unsafe fn add_item(menu: Id, target: Id, title: &str, tag: usize) -> Id {
    let ns = objc_getClass(c("NSString").as_ptr());
    let init: unsafe extern "C" fn(Id, Sel, Id, Sel, Id) -> Id =
        std::mem::transmute(objc_msgSend as unsafe extern "C" fn() as usize);

        msg0(objc_getClass(c("NSMenuItem").as_ptr()), "alloc"),
        sel_registerName(c("initWithTitle:action:keyEquivalent:").as_ptr()),

        sel_registerName(c("menuItem:").as_ptr()),
        msg_string(ns, ""),
    );
    msg_set_id(item, "setTarget:", target);
    msg_set_long(item, "setTag:", tag as c_long);
    msg_set_id(menu, "addItem:", item);
    item
}
```
